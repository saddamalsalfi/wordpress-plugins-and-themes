# تطوير إضافات WordPress وقوالبه

[English](README.md) · [ملف المهارة](skills/wordpress-plugins-and-themes/SKILL.md) · [أمثلة عملية](skills/wordpress-plugins-and-themes/examples/worked-scenarios.md) · [ترخيص MIT](LICENSE)

مهارة مستقلة لوكلاء البرمجة. تميّز بين العقود التي يفرضها WordPress وقت التشغيل وقواعد النشر في WordPress.org وأعراف تسمية المستودعات. تحتوي على تعليمات ومراجع، وليست حزمة أو إضافة أو قالبًا يُثبّت داخل المنصّة. واسم المهارة لا يحدّد معرّف الإضافة أو القالب في المنصّة.

## ما الذي تغطيه؟

- اختيار دورة الحياة للإضافات العادية أو الشبكية أو الإلزامية أو drop-ins، مع حفظ المعرّف ونطاق الترجمة والعقود العامة.
- مراجعة صلاحيات REST لكل كائن وتصدير البيانات الشخصية ومحوها والترحيلات وعزل المواقع على Multisite.
- دعم القوالب الكلاسيكية وقوالب البلوكات والقوالب الفرعية دون فقد المحتوى المحفوظ أو تخصيصات محرّر الموقع.

## التثبيت

انسخ المجلد **`skills/wordpress-plugins-and-themes/` كاملًا** إلى مجلد الاكتشاف في مشروع التطبيق المستهدف. لا تنسخ `SKILL.md` وحده؛ فهو يعتمد على مراجع وأمثلة مرفقة.

| الوكيل | المجلد داخل المشروع |
|---|---|
| Codex | `.agents/skills/` |
| Claude Code | `.claude/skills/` |
| Cursor | `.agents/skills/` أو `.cursor/skills/` |
| GitHub Copilot | `.github/skills/` أو `.agents/skills/` في الواجهات التي تدعمه |
| Google Antigravity | `.agents/skills/` |

راجع [خطوات التثبيت بالنسخ أو بأداة skills](README.md#install) في الدليل الإنجليزي. يمكنك استخدام [قاعدة Cursor اليدوية](rules/wordpress-plugins-and-themes.mdc) بعد تثبيت المهارة، وتثبيت المهارة الأصلية مستقل عن مسار MCP وDocker.

## التشغيل عبر MCP أو Docker

يشغّل Docker خادم MCP للقراءة فقط، ويعرض الخادم المراجع نفسها دون الوصول إلى ملفات مشروعك. يمكن التشغيل محليًا عبر stdio أو Streamable HTTP. راجع [دليل التشغيل والنشر](docs/distribution.md) لإعداد العميل، وبناء صورة Docker، والنشر على GHCR ثم MCP Registry أو تقديم المستودع إلى Glama. الأدلة التي تشترط رابطًا عامًا تحتاج إلى استضافة فعلية على HTTPS.

## مثال استخدام

```text
استخدم مهارة wordpress-plugins-and-themes. راجع إضافة بلوكات WordPress هذه قبل إصدارها. تحقّق من الحد الأدنى المدعوم ومن صلاحيات REST لكل كائن، واختبر البلوكات المحفوظة سابقًا والتثبيت النظيف من ZIP الناتج.
```

## التحقق المحلي

من جذر مستودع المهارة، شغّل الأمر التالي باستخدام Python 3.10 أو أحدث:

```sh
python -B -m unittest discover -s tests -v
```

تتحقق الاختبارات الأساسية من بنية الحزمة ومراجعها. بعد تثبيت تبعيات MCP كما في دليل التشغيل، يشغّل الأمر نفسه اختبارات الاتصال أيضًا؛ وهي لا تشغّل المنصّة نفسها. ترخيص MIT يخصّ المهارة؛ راجع ترخيص الإضافة أو القالب وقواعد قناة نشره بصورة مستقلة.
